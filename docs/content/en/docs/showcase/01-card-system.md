# AIRI Card Character System

![AIRI Card Character System](/showcase/hero-01-card-system.avif)

The **AIRI Card Character System** turns characters into portable, multi-faculty entities — one asset that bundles the 3D/2D vessel, wardrobe, voice profile, acting directives, and operating schedule.

The 10-tab deep editor, the proactivity/memory surfaces, and the import/export and community-hub flows are implemented in the stage-pages card editor and the stage-ui card store and schema.

See the code-colocated [Card Editor & Creation Wizard](https://github.com/7n1m4/AnimA/blob/main/.agents/skills/airi-card-editor-wizard/SKILL.md) and [Card Schema](https://github.com/7n1m4/AnimA/blob/main/.agents/skills/airi-card-schema/SKILL.md) documents for the tab map, the `extensions.airi` bindings, CCv2/CCv3 PNG interop, and ZIP packaging.

> [!NOTE]
> The former **Artistry & Autonomous Director** tab is deprecated and disabled; image generation no longer runs. Existing visual assets remain viewable and are preserved on export/import.
