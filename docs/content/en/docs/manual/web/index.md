# Guide to Web version

The browser build of Anima is the `stage-web` app: a Vite/Vue host that reuses the same `stage-ui` core (character, chat, memory, voice, rendering) as the desktop build, served as a static site.

See the code-colocated [stage-web README](https://github.com/7n1m4/AnimA/blob/main/apps/stage-web/README.md) for the app entry point and host wiring; the shared interaction model is documented in [Ways to Talk & Interact](../interacting), and desktop-specific controls are in [Desktop Controls & Shortcuts](../desktop-controls).
