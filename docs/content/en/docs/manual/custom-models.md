# Custom 3D & 2D Avatars

Anima's avatar loading and customization (VRM, Live2D, Spine, MMD import, the Model Customizer, and the Rehearsal Room) is implemented in the stage-ui model-settings components and the per-engine renderer packages.

See the code-colocated [Custom 3D & 2D Avatars](https://github.com/7n1m4/AnimA/blob/main/packages/stage-ui/src/components/scenarios/settings/model-settings/README.md) document for supported formats, importing, expression mapping, the Rehearsal Room, and performance tuning.
