# How Memory & Continuity Works

Anima's layered memory and continuity model (short-term daily summaries, the append-only text journal, echo chips, universes, and lifetime artifacts) is implemented in the `anima-core` memory crate.

See the code-colocated [Memory Architecture](https://github.com/7n1m4/AnimA/blob/main/crates/anima-core/src/memory/README.md) document for the full model, asset hierarchy, timeline migration policy, and persistence architecture.
