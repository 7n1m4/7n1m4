# Studio

Anima's Studio (the concept stack, Base vs. Layer concepts, actor tokens, outfit pinning, and the deprecated Director generation seam) is implemented in the stage-ui artistry stores.

> [!WARNING]
> AI image generation, including Autonomous Artistry and the Director generation loop, is deprecated and disabled. Existing images remain available as read-only background/journal history; Studio actor-token and static-asset routing still work.

See the code-colocated [Studio Concepts & the Concept Stack](https://github.com/7n1m4/AnimA/blob/main/packages/stage-ui/src/stores/modules/STUDIO-CONCEPTS.md) document for the three pillars, the Base/Layer fold, the three orchestration modes, concept authoring, and troubleshooting.
