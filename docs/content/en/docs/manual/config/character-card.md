# Character & Visuals

Anima's card identity, per-card module overrides, scene backgrounds, and model configuration are implemented in the stage-ui card store, the stage-pages card editor, and the per-engine renderer packages.

See the code-colocated [Character Card, Scenes & Models](https://github.com/7n1m4/AnimA/blob/main/packages/stage-pages/src/pages/settings/airi-card/README.md) document for creating a card, the editor tabs, scene backgrounds, and supported model formats.
