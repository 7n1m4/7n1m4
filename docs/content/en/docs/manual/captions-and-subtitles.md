# Captions, Subtitles & Speech Bubbles

Anima's captioning system (floating caption window, inline chat captions, comic speech bubbles, and Sentence-Sync audio highlighting) is implemented in the stage-ui caption panel and the Electron caption window.

See the code-colocated [Captions, Subtitles & Speech Bubbles](https://github.com/7n1m4/AnimA/blob/main/packages/stage-ui/src/components/scenes/CAPTIONS.md) document for the display surfaces, sentence-sync behavior, and appearance settings.
