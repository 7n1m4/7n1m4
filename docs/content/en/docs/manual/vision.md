# Vision & Screen Perception

Anima's image and screen perception (the dedicated Vision-Language Model routing, attention-ecology screen capture, and cost management) is implemented in the stage-ui vision orchestrator store and composables.

See the code-colocated [Vision Subsystem](https://github.com/7n1m4/AnimA/blob/main/packages/stage-ui/src/stores/modules/vision/README.md) document for sending images, the VLM architecture, token-cost table, and situational awareness.
