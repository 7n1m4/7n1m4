# Desktop Controls & Shortcuts

Anima's desktop controls (the floating Control Strip, window modes and positioning, global keyboard shortcuts, and multi-monitor setup) are implemented in the stage-ui layout components and composables.

See the code-colocated [Desktop Controls & Shortcuts](https://github.com/7n1m4/AnimA/blob/main/packages/stage-ui/src/components/scenarios/layout/DESKTOP-CONTROLS.md) document for the Control Strip buttons, window modes, shortcut table, and multi-monitor behavior.
