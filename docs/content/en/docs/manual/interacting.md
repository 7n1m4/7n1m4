# Ways to Talk & Interact

Anima's text, voice (push-to-talk and open-mic VAD), Gemini Live bidirectional streaming, and Discord interaction paths are wired across the stage-ui chat stores and the native `anima-stt` / `anima-discord` crates.

See the code-colocated [Interaction Pipelines](https://github.com/7n1m4/AnimA/blob/main/packages/stage-ui/src/stores/chat/INTERACTION-PIPELINES.md) document for the mode comparison, chatbox layout, voice setup, Gemini Live, Discord, and interruption behavior.
